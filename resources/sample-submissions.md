# Sample Submissions

**Examples only — not required topics.** Final games must fit the **official theme and constraints** revealed at kickoff.

## Digital / phone-friendly

- One-button dodge game (tap to jump)  
- Merrillville or Gary history quiz  
- Endless runner inspired by local bus routes  
- Rhythm game using claps or taps  
- Replit collection game for a neighborhood event  
- GDevelop platformer about crossing town with limited transit  
- Puzzle about WiFi, charging, or library resources  
- School/work/family balance mini-sim  

## Stories and slides

- Google Slides choose-your-own-adventure  
- Interactive story with local community setting  
- Clickable Canva prototype with labeled screens  

## Paper / tabletop

- Card game about community resources (rules + photos + video)  
- Board game prototype with printable PDF  
- Sports training card game for a local team theme  

## Community connection examples

- “Build your dream community center” concept game  
- Civic resource finder game (concept + demo)  
- Youth program scheduling game in Sheets  

## What judges need to see

1. How your project fits the **theme**  
2. How to **play** or follow it (instructions)  
3. A **demo** (video or playable link)  
4. What you **learned**  

See [Submission Guide](submission-guide.md) and [Judging and Awards](judging-and-awards.md).
