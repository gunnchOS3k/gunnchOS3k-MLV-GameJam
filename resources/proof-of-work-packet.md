# Proof of Work Packet

Every participant or team should leave the jam with a **Proof of Work Packet**. It does not need to be perfect. **It needs to exist.**

Beginners are **not** required to complete the fully loaded packet.

---

## Minimum packet (beginner-friendly — enough to submit)

- [ ] Project name  
- [ ] Team or solo creator name  
- [ ] Short description  
- [ ] Theme connection (once theme is revealed)  
- [ ] How to play or understand the project  
- [ ] Tools used  
- [ ] Screenshots, photos, or demo video  
- [ ] Asset credits  
- [ ] AI-use disclosure if AI helped  
- [ ] What you learned  
- [ ] What you would build next  

Submit via your [itch.io jam project page](https://itch.io/jam/lake-county-phone-first-game-jam).

---

## Fully loaded packet (aspirational)

- [ ] itch.io project page (official submission)  
- [ ] GitHub repo or Replit link  
- [ ] README with play/setup instructions  
- [ ] Google Slides or PowerPoint pitch deck  
- [ ] Demo video  
- [ ] Screenshots / GIFs  
- [ ] Asset and license credits  
- [ ] Optional LaTeX-style technical report  
- [ ] Reproducibility checklist  
- [ ] Resume / LinkedIn bullet  
- [ ] Portfolio or personal project page  
- [ ] Reflection: *“Before this jam, I thought I could not… Now I can…”*  

---

## Phone-only path

A clear idea + working prototype + short demo video + written instructions = a **real portfolio artifact**.

See [Phone-First Toolkit](phone-first-game-dev-toolkit.md) and [Portfolio Readiness](portfolio-readiness.md).

---

## No shame rule

> A finished small game is better than an unfinished giant game.

Submit what you have with a clear demo and honest reflection.
