# Participant Outcomes — Zero-to-Hero Build Sprint

**Walk In Curious. Walk Out Portfolio Ready.**

This guide applies to the **Lake County Phone-First Game Jam** (NWI Summer Game Jam) — planned Summer 2026, virtual-first, phone-first, beginner-friendly.

---

## The transformation framing

- **Zero-to-Hero Build Sprint**
- **Hyperbolic Time Machine Experience** — weeks of creative compression where you learn by making games
- **Participants walk in as curious learners and leave as documented builders.**

This game jam is designed as a **zero-to-hero build sprint**. Participants are not expected to arrive as experts. They are expected to arrive with **curiosity, courage, and willingness to try**. Through rapid problem solving, design thinking, prototyping, documentation, and presentation, participants will leave with more than a memory — they will leave with **proof of work**.

*Nothing here guarantees jobs, prizes, scholarships, or professional status. These outcomes are about **skills and artifacts you earn through participation**.*

---

## What participants practice

| Skill | What it looks like |
|-------|-------------------|
| **Presenting** | Explaining your game to technical and nontechnical audiences |
| **Rapid problem solving** | Making design and scope decisions under jam time limits |
| **Design thinking** | Empathize → define → ideate → prototype → test |
| **Prototyping** | Building games on phones, tablets, laptops, or borrowed devices |
| **Slides** | Creating PowerPoint or Google Slides pitch decks |
| **Documentation** | Writing rules, READMEs, and how-to-play guides |
| **README writing** | One-page explanation anyone can follow |
| **Publishing** | itch.io, GitHub, GitHub Pages, Devpost, or a personal website (when ready) |
| **LaTeX report** | Optional advanced technical write-up |
| **Reproducibility** | Checklist so someone else could play or rebuild your game |
| **Demo video** | Short recording showing gameplay or prototype |
| **Portfolio building** | Turning the jam game into a resume or LinkedIn artifact |

**Beginners are not required to complete every item.** Start where you are.

---

## The Proof of Work Packet

Every participant or team should leave with a **Proof of Work Packet**. It does not need to be perfect. **It needs to exist.**

### Minimum packet (beginner-friendly)

- [ ] Project title  
- [ ] Problem statement or theme interpretation  
- [ ] Who it helps or who would play it  
- [ ] What was built  
- [ ] Tools used  
- [ ] Screenshots or photos  
- [ ] Demo video or live demo  
- [ ] Slides (Google Slides or PowerPoint)  
- [ ] README or one-page explanation (how to play)  
- [ ] What we learned  
- [ ] What we would build next  

### Fully loaded packet (aspirational)

- [ ] Public GitHub repo or portfolio page  
- [ ] GitHub Pages or personal website project page  
- [ ] PowerPoint / Google Slides pitch deck  
- [ ] Technical README  
- [ ] LaTeX-style technical report (optional)  
- [ ] Reproducibility checklist  
- [ ] Demo video  
- [ ] Screenshots / GIFs  
- [ ] Asset and license credits  
- [ ] Resume / LinkedIn bullet  
- [ ] Reflection: *“Before this jam, I thought I could not… Now I can…”*  

The **fully loaded packet is a goal**, not a requirement for beginners.

## Outcome Badge Ladder

Climb at your own pace. Every level counts.

| Level | Badge | You… |
|-------|-------|------|
| 1 | **I Showed Up** | Joined the jam, learned tools, picked a team or solo path |
| 2 | **I Built Something** | Created a game, story, paper prototype, mockup, or demo |
| 3 | **I Explained It** | Presented to a mixed technical/nontechnical audience |
| 4 | **I Documented It** | Created slides and a README or how-to-play guide |
| 5 | **I Published It** | Posted to itch.io, GitHub, GitHub Pages, Devpost, or a personal site |
| 6 | **I Made It Reproducible** | Added setup steps, tool list, assets, credits, and play instructions |
| 7 | **I Became Portfolio Ready** | Left with a project page, demo video, and resume bullet |

> **A phone-only beginner can still complete the ladder.** A clear idea, a working prototype, a short video, and strong documentation can be a real portfolio artifact.

---

## Pressure with guardrails

This is meant to be a **positive pressure-cooker experience**, not burnout or humiliation. The jam stretches you with deadlines, teamwork, demos, and public explanation — while offering optional Friday office hours, phone-first tools, beginner paths, youth safety rules, and encouragement.

> **The pressure is the mold, but support is the safety rail.**
