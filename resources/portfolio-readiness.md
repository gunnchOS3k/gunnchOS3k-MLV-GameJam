# Portfolio Readiness

Turn your jam submission into something you can show **after** the deadline — for school, work, or your own confidence.

**No cash prizes** — but a strong portfolio artifact has long-term value.

---

## What you can leave with

- A game, prototype, story, or demo  
- Public **itch.io** project page  
- Short project explanation (README or jam page text)  
- Screenshots or demo video  
- Tools-used list  
- Proof of Work Packet  
- Reflection on what you learned  
- Optional GitHub, Replit, or personal website link  
- Optional resume or LinkedIn bullet  

---

## itch.io project page

Your official submission lives on [itch.io](https://itch.io/jam/lake-county-phone-first-game-jam). After the jam:

- Keep the page public as a portfolio piece  
- Add a polished description and screenshots  
- Link your demo video  

---

## GitHub

- Create a public repo with README, screenshots, and how to play  
- Add a license if you want others to learn from your code  
- Link the repo from itch.io and LinkedIn  

---

## Personal website / GitHub Pages

- One page: title, problem, what you built, demo embed or link, what you learned  
- Mobile-friendly layout — many viewers will be on phones  

---

## LinkedIn post (example structure)

- Hook: what you built in one sentence  
- Theme connection  
- Tools used (phone-first angle if true)  
- Link to itch.io page  
- What you learned  
- Gratitude to teammates/mentors  

---

## Resume bullet (example)

> Built and submitted a phone-first [genre] game for the Lake County Phone-First Game Jam; documented design, playtest feedback, and demo video on itch.io.

Adjust to truth — never exaggerate skills you did not use.

---

## Class or school portfolio

- Include screenshots, rules doc, and reflection paragraph  
- Explain design thinking steps: empathize, define, ideate, prototype, test  

---

## Presentation artifact

- Reuse Google Slides from the jam for a 3–5 minute presentation  
- Lead with demo video, then problem → solution → learnings
